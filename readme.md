Chat Interno com WebSocket

Sistema de chat em tempo real desenvolvido com Node.js, Express e WebSocket (ws), com interface moderna e responsiva.

🚀 Funcionalidades
1. Chat em tempo real;
2. Comunicação via WebSocket;
3. Interface moderna;
4. Login simples com nome de usuário;
5. Mensagens coloridas automaticamente para cada usuário;
6. Suporte para múltiplos clientes conectados;
7. Design responsivo;
8. Compatível com desktop e mobile.

🛠️ Tecnologias Utilizadas
Node.js
Express
WebSocket
HTML5
CSS3
JavaScript Vanilla

🌐 Como Funciona

O servidor cria uma conexão WebSocket com todos os clientes conectados.

Quando um usuário envia uma mensagem:

A mensagem é enviada ao servidor
O servidor recebe a mensagem
O servidor retransmite para os outros clientes conectados
Cada cliente exibe a mensagem em tempo real
